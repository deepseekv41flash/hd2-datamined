## 4 四条值得记住的结论

1. **飞刀的伤害就长在这里**：K-2 飞刀没有爆炸，`+0x2C` = 伤害行 **648** 就是它的命中伤害
   （与 hd2runtime `ThrowingKnifeDamage` 示例的说法一致："Its hit damage is the DamageInfo row its
   StickyComponent names"；他们那份是 636，本 build 漂到 648）。
2. **G-123 热熔的 sticky 是最小配置**：两组 flag 里只有 `+0x20=1`，**没有命中伤害行**（`+0x2C=0`），
   也没有 Ability —— 所以热熔的伤害**全部来自爆炸 201 → 伤害行 352**，粘附只负责"贴上去"。
   这也解释了为什么 `Thermite` 状态 id 13 在数据里没人引用（见 [STATUS-EFFECTS](STATUS-EFFECTS-26088801.md) §5）。
3. **地雷/护盾类共用一对 AbilityId**（526/527 · 1238/2069 · 2068/2069 · 2081/2082）——
   像"贴住 → 武装/起爆"的两个能力槽；这是把"粘住后干什么"接到别处的天然钩子。
4. **`+0x08` 全表 `(-90,0,0)`**：粘附时统一把物体按 -90° 贴合表面；`+0x14` 只有旗子有
   `(0,0,1.125)` 的举高偏移。

## 0 一句话

`MountComponentData` 行 17 的 slot 0/1 换成外来臂件（8 字节 ×2）；
再把两个**不占战备位的常驻行**的 `+0xA8` 填成**源机甲的包 id**，
让引擎在**关卡加载时**就把这两个包驻留 —— 于是外来臂的网格有得画，不会退化成紫色问号。

## 3 包驻留：纯数据怎么做（这轮的关键）

引擎只自动加载「**原版槽位物品**」的包（本仓库 [LIMITED-CROSS-PACKAGE-LOADING §1](../engine/LIMITED-CROSS-PACKAGE-LOADING-26088801.md)
的来源 C）；外来件的包要**自己声明**。该文档里已经实机验证了两条：

| 结论 | 出处 | 态 |
|---|---|---|
| `StratagemSettings` 行 `+0xA8` 在**关卡加载时**被读（不叫、不带也生效） | 该文 R3（`Reinforce` 行 57/138） | ✓ 实机 |
| `Reinforce`（行 57/138）与 `SOS Beacon`（行 59）**不占战备位** ⇒ 声明包是"免费"的 | 该文 R3 / R9 | ✓ 实机 |
| `+0xF8` 只在**该战备授予武器**时被读 ⇒ 机甲不授予武器，用不了 | 该文 R1 | ✓ 实机（否证） |

所以这轮用**两个免费口**：

| 行 | `+0xA8` 原值 | 写入 | 意图 |
|---|---|---|---|
| `Reinforce` 行 57 与 138（**两行都要**，同战备的重复行） | `0` | `0x7DE417DB7552D9FC` | 突破者包（盾） |
| `SOS Beacon` 行 59 | `0` | `0x0A4BD8A1833F11B2` | 伐木者包（加农炮） |

行号/偏移都是**现算**的（`pod_loadout.strat_groups` 逐组枚举，`+0xA8` = 行基址 + `0xA8`）：
本 build 153 行，行 57 → `0x7084`、行 59 → `0x73A4`、行 138 → `0x12524`（文件绝对偏移）。

## 5 进游戏怎么验

1. **正常带 EXO-45 即可**（不需要带 EXO-55 / EXO-51，也不需要任何 runtime）；
2. 召唤「爱国者」⇒ 看两条手臂：

| 读数 | 判定 |
|---|---|
| 左臂**盾** + 右臂**加农炮**，模型正常 | ✓✓ 换臂 + 纯数据跨包驻留**都成立**，memmod 期实验在数据路线复现 |
| 某一侧**紫问号** | 该包的"免费口"没生效（或该包名写错）⇒ 看是哪一侧，单变量重试 |
| 某一侧仍是**原版** | 该槽的挂载记录没被引擎读（或战备召唤走的是另一条记录）⇒ 先用 [MOUNT-SEATS §7](../tables/MOUNT-SEATS-26088801.md) `verify` 复核盘上文件 |
| 模型在但**倒挂/歪** | 侧别问题 ⇒ 只换同侧件（本轮两侧都是同侧换，理论上不会） |

3. 附带可看：盾的举盾/减伤行为是**件自带**的，不需要额外改；右臂加农炮开火应直接可用。

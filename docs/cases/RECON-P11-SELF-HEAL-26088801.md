## 3 归层：**L4 · 运行时事件 + 引擎函数调用** ⇒ C 档

要"开火即回血"，必须同时具备两件数据表给不了的东西：

1. **事件**：接收"本地玩家开了一枪（还是 P-11）"这个通知 —— 数据表里没有"每次开火自动施加状态"的字段；
2. **调用**：调用引擎的治疗函数（`AddHealthFraction` / 部位恢复）—— 数据侧只能提供"伤害行 → 状态槽"这种**载体**，不能主动调用。

⇒ 按本仓库词表：**C · 不可实现**（不是"做不了回血"，而是**"开火即回血"这个形态**做不了）。

⚠ 一个必须写清的反转：README 说运行时**明确不允许**施加 stim 类状态（SDK 原文 "Not supported: … stim"），
所以它只能走 `AddHealthFraction`。而我们的**数据路线施加的正是状态 29（Stim Pistol Heal）** ——
它拿不到的那一层，我们拿到了。**能力面各有胜负，不是单方面替代。**

## 6 这个案例怎么用（C 档写法）

1. **卡点一句话**：「数据里没有开火事件，只有伤害/状态载体」——不要写成"做不到回血"。
2. **替代必须带实测值**：打脚下 ✓ / >2 m ✗（两个方向都要测，否则分不清是"半径"还是"全局"）。
3. **残余差距写成用户能感知的差别**：不用瞄准 vs 必须打脚下；**加速/耐力未验**（部位已 ✓ 实机）。
4. **别再花局验**：不要试图给手枪加 spray 组件（组件不可新增）、不要试图让弹丸"零距离自爆"
   （弹丸没有自爆字段）、不要指望 `+0x90/+0x9C` 之外还有"开火时触发"的爆炸挂点。
